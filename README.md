# 📱 MoneyBuddy2

## 📌 Overview

MoneyBuddy2 is an Android application designed to help users track their expenses, manage budgets, and gain insights into their spending habits. The app focuses on simplicity, real-time tracking, and user-friendly data visualization.

---

## 🚀 Features

* 💰 Expense tracking by category
* 📊 Analytics dashboard for spending insights
* 🧾 Receipt scanning / logging *(if applicable)*
* 🔍 Transaction history view
* 🎯 Budget management

---

## 🛠️ Tech Stack

* **Language:** Kotlin
* **Framework:** Android SDK / Jetpack Compose
* **Datbase:** Firebase
* **Architecture:** MVVM
* **Tools:** Android Studio
* **Other:** REST API integration *(if used)*

## ⚙️ Setup Instructions

### 1. Clone the repository

```
git clone https://github.com/your-username/MoneyBuddy2.git
```

### 2. Open in Android Studio

* Open Android Studio
* Select **Open Project**
* Choose the cloned folder

### 3. Configure API Keys

Create a `local.properties` file and add:

```
API_KEY=your_api_key_here
```

### 3. Configure API Keys

This app connects to a locally hosted backend server.

To run the app:

Open the file where BASE_URL is defined
Replace the IP address with your machine’s IP:
val BASE_URL = "http://YOUR_IP_ADDRESS:8080"
Example:
val BASE_URL = "http://192.168.1.10:8080"

>⚠️ Ensure your backend server is running and both devices are on the same network.

---

## ▶️ Running the App

* Connect an Android device
* Click **Run ▶️** in Android Studio
